## 🟫 Slide 2 — What Is This Project?
**Background:** `#171819` (Dark Charcoal)
**Heading color:** `#e3be7f` (Gold)

### What Is DELICI?

DELICI is a **restaurant landing page** — a single webpage that acts as the online face of a fine-dining restaurant.

Think of it like a digital brochure that:
- 🍴 Shows the restaurant's menu
- 📖 Tells the restaurant's story
- 📅 Lets customers book a table online
- 👨‍🍳 Introduces the chefs
- 🎉 Announces upcoming events

> **Simple goal:** A visitor lands on the page and immediately feels like they want to eat there.

## 🟫 Slide 10 — Design Choices
**Background:** `#171819` (Dark Charcoal)
**Heading color:** `#e3be7f` (Gold)

### Why Does It Look This Way?

**Color Palette:**

| Color | Hex | Why? |
|---|---|---|
| Deep Black | `#0a0a0a` | Luxury, elegance |
| Dark Charcoal | `#171819` | Depth, contrast |
| Warm Gold | `#e3be7f` | Premium feel, appetite |
| White | `#ffffff` | Readability |
| Gray | `#9b9b9b` | Supporting text |

**Fonts:**
- **Forum** (serif) → Headings — feels classic and upscale
- **DM Sans** (sans-serif) → Body text — clean and modern

> The dark + gold combination is a classic fine-dining visual language. Think high-end menus and luxury brands.

## 🟫 Slide 12 — Responsive Design
**Background:** `#171819` (Dark Charcoal)
**Heading color:** `#e3be7f` (Gold)

### It Works on Every Screen

The website adapts to different screen sizes:

```
🖥️  Desktop          📱 Tablet           📱 Mobile
─────────────       ─────────────       ─────────────
[  Col  Col  Col ]  [  Col    Col  ]    [    Col     ]
[  Col  Col  Col ]  [  Col    Col  ]    [    Col     ]
Full layout         2-column grid       Single column
All sections        Some hidden         Hamburger menu
visible             elements            navigation
```

**How?** Bootstrap 5's grid system with breakpoints:
- `col-lg-4` → 3 columns on desktop
- `col-md-6` → 2 columns on tablet
- `col-sm-12` → 1 column on mobile

## 🟫 Slide 14 — Challenges & Learnings
**Background:** `#171819` (Dark Charcoal)
**Heading color:** `#e3be7f` (Gold)

### What Was Tricky?

**Challenges faced:**
- 🎬 Making the video fill the screen on all devices without distortion
- 📐 Overlapping images in the "Our Story" section (absolute positioning)
- 📱 Hiding certain columns on mobile while keeping the layout clean
- 🎨 Keeping a consistent dark theme across all 13 sections
- ✨ Combining AOS animations with Bootstrap without conflicts

**What I learned:**
- How to use CSS `position: absolute` for creative layouts
- How Bootstrap's responsive classes work together
- How to layer a video background with a dark overlay
- How to create smooth hover transitions with CSS
